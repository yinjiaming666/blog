wsl2 docker 拉取镜像出现 Error response from daemon: Get xxx : proxyconnect tcp: dial xxx connect: connection refused 问题

2025-06-04 · 随笔

默认情况下，WSL2会在windows的用户目录（一般是C:/Users/<你的用户名> /）下创建一个隐藏的.wslconfig文件，这个文件中，有一个设置networkingMode，默认情况下可能是这样的：

networkingMode=mirrored

此时，如果你想运行docker pull xxx命令，就会出现类似于下面的bug

Error response from daemon: Get "https://registry.cn-hangzhou.aliyuncs.com/v2/": proxyconnect tcp: dial tcp 127.0.0.1:10080: connect: connection refused

解决方法

删除 networkingMode=mirrored 这行

局域网内访问 wsl2 中的服务

hostAddressLoopback=true
