for-select 导致 cpu 占用高的问题

2023-12-04 · Go

package server

import (
    "fmt"
    "time"
)

func InitServer(port string) {
    for i := 0; i < 10; i++ {
       go listen()
    }
}

func listen() {
    defer func() {
       fmt.Println("协程关闭")
    }()
    for {
       select {
       case <-chargePile.Ctx.Done():
          // 退出信号
          return
       default:
          // 业务代码

          // 如果不加这行，default 会一直空跑抢占 cpu 资源
          time.Sleep(10)
       }
    }
}

如果for循环体一直处于繁忙状态，则cpu被一直抢占，而cpu居高不下，如果循环体有io等待则会出让cpu，不会一直抢占

select 在有default的情况下，很容易造成类似for死循环 抢占cpu的情况
