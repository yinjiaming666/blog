redis 防止商品超卖

2022-11-11 · PHP

$redisCli->set($key, $num); // 设置商品库存 num
$res = $redisCli->decrby($key, 1); // 用户购买，如果 res 为负数，说明商品库存为0

如果一次可以购买多个商品就需要去用 redis 执行 lua 脚本

$script = <<<crifan
        local num = redis.call('get', '$key') or 0
        num = tonumber(num)
        if num >= $num then
            redis.call('decrby', '$key', $num)
            return "success"
        else
            return "fail"
        end
crifan;
$res = $redisCli->eval($script);
