macos corntab 定时任务不执行

2022-08-04 · 随笔

corntab 配置成功后，定时任务不触发，后来发现执行的是一条 docker 命令

os.system('docker exec -it heima_server bash -c "cd /app/heima_server/server && php /app/quick-yet-swoole/QYS/QYS.php -p
/app/heima_server/server -c conf/debug.php -f  /app/heima_server/server/task/test.php " ')

docker 必须要用绝对路径并且不能带 -it

os.system('/usr/local/bin/docker exec heima_server bash -c "cd /app/heima_server/server && php /app/quick-yet-swoole/QYS/QYS.php -p
/app/heima_server/server -c conf/debug.php -f  /app/heima_server/server/task/test.php " ')

改成这样好用了

corntab 一定要用绝对路径包括 python 等
