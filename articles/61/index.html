对象赋值 (clone)

2023-02-03 · PHP

php 对象赋值的时候，传递的是对象的地址

$objA = new BannerModel($mysql);
$objB = $objA; // objB 指向的是 objA 的地址，等同于 $objB = &$objA
$objA->id = 1;
var_dump($objB->id); // 输出 1。如果 objA 的值发生改变，objB 也会改变，反之亦然。

// 如果不想传递地址需要使用 clone 关键字
// 使用 clone 会在内存中开辟一个新地址
$objB = clone $objA; // 会触发 __clone 魔术方法
