flutter addPostFrameCallback

2025-07-31 · 前端

说明

WidgetsBinding.instance?.addPostFrameCallback

方法用于在当前帧绘制完成后执行一个回调函数。在这个回调函数中，可以执行一些需要在 widget 渲染完成后才能执行的操作，例如获取 widget 的尺寸、位置信息等。 类似于 Vue 中的 nextTick

使用场景

Overlay.of(_ctx).insert(overlayEntry);
// 等待 overlay 加载完成之后再执行下一步操作
WidgetsBinding.instance.addPostFrameCallback((_) => ctrl.start());
