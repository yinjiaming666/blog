docker logs 参数说明

2024-01-15 · 随笔

参数 说明 示例
-f 跟踪日志输出
-t 显示时间戳
--since 显示某个开始时间的日志 2024-01-14T19:00:00.999999999
--until 显示某个结束时间的日志 2024-01-14T19:00:00.999999999
--tail 仅列出最新N条容器日志 50
grep "" 搜索指定内容 string
>> 输出到指定文件 >> docker.log

完整示例

docker logs -f 容器名 --since '2024-01-01T19:00:00' --until='2024-01-31T20:00:05' | grep "要搜索的内容" >> 要输出的文件
