composer 忽略 PHP 扩展版本

2022-07-28 · PHP

composer 安装包的时候会校验 PHP 的版本及扩展，如果我们的环境是搭建在 docker 中，composer 就会提示类似 - yansongda/pay[v2.10.0, ..., v2.10.4] require ext-bcmath * -> it is missing from your system. Install or enable PHP's bcmath extension. 的错误。

方法一

定义 composer.json

{
  "require": {
    "yansongda/pay": "^2.10.0",
    "ext-bcmath": "*",
    "ext-json": "*",
    "ext-curl": "*",
    "ext-libxml": "*",
    "ext-simplexml": "*"
  },
  "repositories": {
    "packagist": {
      "type": "composer",
      "url": "https://mirrors.cloud.tencent.com/composer/"
    }
  },
  "config": {
    "platform": {
      "php": "7.2.5",
      "ext-bcmath": "4.0.3"
    }
  }
}

告诉 composer 当前 PHP 版本为 7.2.5，安装了 ext-bcmath 扩展

{
  "config": {
    "platform": {
      "php": "7.2.5",
      "ext-bcmath": "4.0.3"
    }
  }
}

指定使用阿里云镜像

{
  "repositories": {
    "packagist": {
      "type": "composer",
      "url": "https://mirrors.cloud.tencent.com/composer/"
    }
  }
}

方法二

命令行携带参数

composer install --ignore-platform-reqs
