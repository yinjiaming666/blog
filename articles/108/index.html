mysql GROUP_CONCAT 函数长度限制

2024-08-08 · 随笔

Mysql中的group_concat()函数是有长度限制的，默认为1024字节，当组合的数据过多时会出现丢失数据的情况

SHOW VARIABLES LIKE "group_concat_max_len"; # 查询最大值
SET GLOBAL group_concat_max_len = -1; -- -1 为不限制大小
SET GLOBAL group_concat_max_len = 10240000;
SET SESSION group_concat_max_len = 10240000;
