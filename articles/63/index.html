tmux 基本命令

2023-02-22 · 随笔

  • tmux ls 查看窗口列表
  • tmux new -s name 新建窗口
  • tmux attach -t name 切换到窗口
  • ctrl + b + d 退出窗口(先按 ctrl + b 松开后再按 d)
  • ctrl + b + [ 开启翻页模式
  • tmux kill-session -t name 删除窗口
