shell 获取返回值

2023-09-28 · Go

golang main 函数没有返回值，只能通过 os.Exit 返回 int 类型的 code.

#!/bin/sh
go run main.go
res=$?
echo "$res"

如果想返回字符串类型，可以使用 golang 向文件写入内容，shell 读取文件这种方式解决

#!/bin/sh
go run main.go
res=$?
if [ $res = 0 ]; then
  echo "退出成功"
  a=$(cat .pwd)
  echo "$a"
  cd "$a" || exit
fi
