2024-02-07 · 随笔

记一次 Mysql 商品超卖

问题描述：在并发高的情况下。事务 A 先读取商品库存为 2 并减少库存，此时事务尚未提交。第二次请求就进来了，事务 B 读取的库存还是 2 ，导致了商品超买的问题。

解决方案：使用乐观锁，update set num = num - 1 where id = id and num = 2
