记一次 gorm 自动写入创建时间失效

2024-01-11 · Go

声明结构体时如果设置了 default 会导致自动写入创建时间失效


CreateTime int64 `json:"create_time" gorm:"autoCreateTime;type:BIGINT UNSIGNED NOT NULL;default:0"` // 自动写入时间戳（失效）
CreateTime int64 `json:"create_time" gorm:"autoCreateTime;type:BIGINT UNSIGNED NOT NULL;"` // 正常
