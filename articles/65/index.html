Mysql 每 15 秒分组

2023-02-23 · 随笔

SELECT
	CONCAT(DATE_FORMAT( tick, '%Y-%m-%d %H:%i:' ), LPAD( FLOOR( SECOND ( tick )/ 15 )* 15, 2, '0' )) AS time,
	MAX( price ) AS high,
	MIN( price ) AS low,
	GROUP_CONCAT( price ),
	COUNT( 1 ) AS num
FROM
	s_real_time_cycle
GROUP BY
	time;

tick 为 timestamp 类型

GROUP_CONCAT 函数跟 group by 一起用，把该字段的值打印在一行逗号分隔
