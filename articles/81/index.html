匿名结构体

2023-11-24 · Go

如果一个结构只打算被使用一次，通常会使用匿名结构体

示例

第一个花括号内声明结构体元素，第二个花括号给结构体赋值


package main

func main() {
    s := struct {
       name string
       age int
    }{str: "张三", num: 18}
    println(s.name)
}
