sprintf

2022-11-09 · PHP

sprintf('数字：%d，字符串：%s', 1, '字符串'); // 输出 数字：1，字符串：字符串
sprintf('数字：%d，字符串：%d', 1, '字符串'); // 输出 数字：1，字符串：0，前后类型不符合会强制转换
sprintf($price, '%.2f'); // 保留小数点后两位
占位符 含义
%% 返回百分比符号
%b 二进制数
%c 依照 ASCII 值的字符
%d 带符号十进制数
%e 可续计数法（比如 1.5e+3）
%u 无符号十进制数
%f 浮点数(local settings aware)
%F 浮点数(not local settings aware)
%o 八进制数
%s 字符串
%x 十六进制数（小写字母）
%X 十六进制数（大写字母）
