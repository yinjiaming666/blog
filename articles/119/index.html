flutter 组件和生命周期

2025-07-18 · 前端

StatelessWidget 和 StatefulWidget 都继承于 Widget,flutter文档中说明 Widget是不可变的,可以在源码中Widget左上角有一个 @immutable注解，这个注解的意思是所有的属性必须是final修饰，也就是Widget一旦初始化以后，其属性将不可变。

StatelessWidget

内容被创建出来之后，就不能再改变了，适合纯静态的组件

生命周期

只有 build 初始化之后就没操作了

StatefulWidget

每次 setState 都会重绘一次组件

  • StatelessWidget和StatefulWidget没有本质区别，他们的所有属性都是不可变的。它们都没法更新，除非用一个新的Widget去替换它们。
  • StatefulWidget拥有一个可变的State。

生命周期
initState 初始化 相当于 onLoad
build 返回需要渲染的 Widget
deactivate 当 State 对象从树中暂时移除时调用
dispose 永久移除，执行最终清理
didUpdateWidget 父组件重绘，导致当前 StatefulWidget 组件调用 build 重绘
