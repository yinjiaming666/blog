Mysql 大分页优化

2022-11-08 · 随笔

SELECT * FROM s_football_player ORDER BY id DESC LIMIT 760000, 10 -- 1.0s

可以通过子查询的方式优化

SELECT *
FROM s_football_player
WHERE id >= (SELECT id FROM s_football_player ORDER BY id DESC LIMIT 760000, 1)
LIMIT 10 -- 0.4s
