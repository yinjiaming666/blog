死锁定义

发现是这两条 sql 冲突

UPDATE s_yifangshang_goods_details set shengyu=0 where goods_id = 799 and `index` = 2 and `type` < 0 and `type` >= -60 and is_del = 0 and shengyu > 0 and `end` <= 10

UPDATE s_yifangshang_goods_detailsSET `shengyu`=0WHERE `goods_id` = 799 and `index` = 2

通过排查代码发现原因

先在事务中执行的第一条sql，第二条sql是在队列中执行的，第一条sql事务尚未体交，第二条sql就已经执行了。

解决方法

第二条sql包含了第一条，程序判断如果执行第二条sql的情况下，就不执行第一条sql。
