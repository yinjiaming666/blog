## ArrayAccess Countable IteratorAggregate JsonSerializable 接口详解

在 thinkPHP 中，分页（Paginator）实现了 `ArrayAccess` `Countable` `IteratorAggregate` `JsonSerializable` 四个接口，

```php
abstract class Paginator implements ArrayAccess, Countable, IteratorAggregate, JsonSerializable
```

### ArrayAccess

ArrayAccess 有四个方法存根 `offsetExists` `offsetGet` `offsetSet` `offsetUnset`提供像访问数组一样访问对象的能力的接口

```php
class Obj implements ArrayAccess
{
    public $items = [];

    public function offsetExists($offset): bool
    {
        // isset($obj['title'])
        return array_key_exists($offset, $this->items);
    }

    public function offsetGet($offset)
    {
        // $obj['title']
        return $this->items[$offset];
    }

    public function offsetSet($offset, $value)
    {
        // $obj['title'] = 1
        if (is_null($offset)) {
            $this->items[] = $value;
        } else {
            $this->items[$offset] = $value;
        }
    }

    public function offsetUnset($offset)
    {
        // unset($obj['title'])
        unset($this->items[$offset]);
    }
}
```

### Countable

类实现 Countable 可被用于 count() 函数

```php
<?php

class Obj implements Countable
{
    public $items = [];
    public function count(): int
    {
        return count($this->items);
    }
}

$obj = new Obj();
$obj->items = ['test' => 1, 'test2' => 2];
var_dump(count($obj)); // 输出2
```

### IteratorAggregate

类实现 IteratorAggregate 可被用于 foreach() 函数

```php
<?php

class Obj implements IteratorAggregate
{
    public $items = [];

    public function getIterator(): ArrayIterator
    {
        return new ArrayIterator($this->items);
    }
}

$obj = new Obj();
$obj->items = ['test' => 1, 'test2' => 2];
foreach ($obj as $value) {
    var_dump($value);
}
```

### JsonSerializable

实现 JsonSerializable 的类可以 在 json_encode() 时定制他们的 JSON 表示法。

```php
<?php

class Obj implements JsonSerializable
{
    public $items = [];

    public function jsonSerialize()
    {
        return $this->items;
    }
}

$obj = new Obj();
$obj->items = ['test' => 1, 'test2' => 2];
var_dump(json_encode($obj));
```
