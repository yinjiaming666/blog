# css `flex: 1;` 注意事项

在 flex 中 `flex: 1;` 的作用是让元素占满父元素剩余空间。但 flex 子项默认有 min-width: auto ，它不会比内容的最小宽度更窄。
所以下面这段代码如果我们不加 `min-width: 0;` 的话，子元素虽然会占满剩余空间，但是不会显示省略号会撑开父元素。

```scss
.spec-item {
  display: flex;
  align-items: center;
  gap: 12px;
  font-size: 12px;
  min-width: 0; // 关键

  .spec-label {
    color: #999;
    min-width: 130px;
  }

  .spec-value {
    color: #333;
    flex: 1;
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
  }
}
```
