# Flutter RichText 用法

```dart
RichText(
  text: TextSpan(
    children: [
      TextSpan(
        text: "热门话题",
        style: TextStyle(fontSize: 12.w, color: Color.fromRGBO(153, 153, 153, 1), height: 16 / 12),
      ),
      WidgetSpan(
        child: SizedBox(
          height: 16.w,
          child: Icon(Icons.arrow_forward_ios, size: 12.w, color: Color.fromRGBO(153, 153, 153, 1)),
        ),
      ),
    ],
)  
```
