# Mysql json 类型字段判断相等

``` sql
SELECT *
FROM s_car
WHERE 1 = 1
  AND invoice_id = "100820000000202306190009"
  AND sku = 765207
  AND attributes = CAST('[{"name":"value","value":"value"}]' AS json)
  AND selection = CAST('[{"name":"名称","values":[{"name":"名称","additi_charge":"差价","type":"all"}]}]' AS json)
  AND bundle_item_list =
      CAST('[{"product_item_id":"","product_id":"","sku":"","name":"","different_price":"","unit":"","qty":"","department":"","selection":[]}]' AS json)
      
-- CAST( '[{"name":"value","value":"value"}]' AS json ) -- CAST ('字符串' AS json) 可以将字符串格式化为 json，从而进行 json 字段比较
```
