# 一次遍历生成无限级树状结构

## php 版本
``` php
// code 为唯一标识
$arr = $areaModel->select();
$arr = array_column($arr, null, 'code'); // 将 code 作为数组的 key
$tree = [];
foreach ($arr as $value) {
    if (isset($arr[$value['pid']])) {
        $arr[$value['pid']]['children'][] =& $arr[$value['code']];
    } else {
        $tree[] =& $arr[$value['code']];
    }
}
```

## golang 版本

tempMap := make(map[uint]*RolesFormat)
