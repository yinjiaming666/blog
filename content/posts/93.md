# for 循环使用简写三元运算符（?:）导致内存溢出

```php
foreach ($goodsList as $goods) {
    for ($j = 0; $j < $goods['weight'] ?: 1; $j++) {
        $t[$goods['seat']][] = $goods;
    }
}
// 该写法会导致内存溢出提示
// Fatal error: Allowed memory size of 134217728 bytes exhausted (tried to allocate 134217736 bytes)

foreach ($goodsList as $goods) {
    $goods['weight'] = $goods['weight']  ?: 1;
    for ($j = 0; $j < $goods['weight']; $j++) {
        $t[$goods['seat']][] = $goods;
    }
}
// 改为此方式解决
```
