> response-rewrite 插件支持修改上游服务或 APISIX 返回的 Body 和 Header 信息。

### 示例
``` json
{
  "plugins":{
    "response-rewrite": {
      "disable": false,
      "filters": [
        {
          "regex": "khms0.googleapis.com",
          "replace": "google.yinjiaming.top/khms0",
          "scope": "global"
        }
      ]
    }
  }
}
```
该示例会把响应体中所有的 "khms0.googleapis.com" 替换为 “google.yinjiaing.top/khs0”

> 如果响应乱码了，可能是因为上游服务的响应体被进行了压缩。可以将请求头带上不接收压缩响应参数（gzip;q=0,deflate,sdch）以解决这个问题
```json
{
  "plugins":{
    "proxy-rewrite": {
      "headers": {
        "accept-encoding": "gzip;q=0,deflate,sdch"
      }
    }
  }
}
```
### 完整示例
```json
{
  "plugins":{
    "response-rewrite": {
      "disable": false,
      "filters": [
        {
          "regex": "khms0.googleapis.com",
          "replace": "google.yinjiaming.top/khms0",
          "scope": "global"
        }
      ]
    },
    "proxy-rewrite": {
      "headers": {
        "accept-encoding": "gzip;q=0,deflate,sdch"
      }
    }
  }
}
```
