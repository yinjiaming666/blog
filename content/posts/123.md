# MySQL innodb 数据恢复

每张表分 `idb` 和 `frm` 两个文件，`frm` 存放表结构 `idb`存放表数据

MySQL 开启 innodb_file_per_table=1

先通过 `mysqlfrm` 获取表结构
```shell
#！/bin/bash
for file in $(ls  ./data)
do
    if [ "${file##*.}" = "frm" ]; then
     echo ./data/${file}
    mysqlfrm --diagnostic  ./data/${file} >> 1.sql
    fi
done
```

执行 alter table discard tablespace 语句
```shell
ALTER TABLE fa_qqw_model DISCARD TABLESPACE;
```

再把idb文件复制到MySQL对应目录

执行
```shell
alter table fa_admin import tablespace;
```
