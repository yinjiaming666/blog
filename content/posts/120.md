# flutter 根据条件显示组件

## 方法一

```dart
if (isLogin) ...[
  Text("已登录", style: TextStyle(color: Colors.white)),
] else if(1 == 1) ...[
  Text("未登录", style: TextStyle(color: Colors.white)),
],
```

## 方法二 （Visibility组件）
```dart
Visibility(
  visible: condition, // condition 是一个布尔值，用于控制显示与否
  child: MyWidget(), // 当condition为true时显示的组件
  maintainState: true, // 可选参数，如果为true，则即使不可见，也会保留组件的状态，默认为false
  maintainSize: true, // 可选参数，如果为true，则即使不可见，也会保留组件所占用的空间，默认为false
)
```
