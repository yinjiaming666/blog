今天遇到了一个需求

![](https://file.yinjiaming.top/api/index/static/blog/1675238057.jpeg)

要查询出同时满足这两个条件的用户 （config_type = eud && value = 1）（config_type = income && value = 2）

查了很久终于想出了一个笨办法

SELECT

uid

FROM

s_user_extend

WHERE

( extend_type, config_type, `value` ) = ( 0, "edu", 1 )

OR

( extend_type, config_type, `value` ) = ( 0, "income", 2 )

GROUP BY

uid

HAVING

COUNT( uid ) = 2

通过 count 条数来判断哪个用户都满足了这两个条件
