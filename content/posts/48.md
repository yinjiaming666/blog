## Mysql this is incompatible with sql_mode=only_full_group_by

### 原因
高版本 Mysql 默认开启 `ONLY_FULL_GROUP_BY` 导致 不允许查询非 `group by` 的字段

### 解决方法

1. 设置 mysql.ini
2. `SET @@global.sql_mode ='STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_AUTO_CREATE_USER,NO_ENGINE_SUBSTITUTION';` 重启后失效
3. 用 `any_value()` 把非 `group by` 字段包起来

如果报错内容为：
```
Expression #2 of ORDER BY clause is not in GROUP BY clause and contains nonaggregated column '
a.createtime' which is not functionally dependent on columns in GROUP BY clause; this is incompatible with
sql_mode=only_full_group_by
```

`SET GLOBAL sql_mode=(SELECT REPLACE(@@sql_mode,'ONLY_FULL_GROUP_BY',''));`
