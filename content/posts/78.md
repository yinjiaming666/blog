# 关于 swoole 协程

### 例子1

> 单个协程

```php
go(function () {
    $startTime = microtime(true);
    for ($i = 0; $i < 5; $i++) {
        var_dump($i);
        co::sleep(1); // 模拟 IO
    }
    $endTime = microtime(true);
    $executionTime = ($endTime - $startTime) * 1000;
    echo "程序执行时间：" . $executionTime . "毫秒";
});
// 输出结果
// int(0)
// int(1)
// int(2)
// int(3)
// int(4)
// 程序执行时间：5005.7110786438毫秒%
```

### 例子2

> 多个协程

```php
$startTime = microtime(true);
for ($i = 0; $i < 5; $i++) {
    go(function () use ($i) {
        var_dump($i);
        co::sleep(1); // 模拟 IO
    });
}
$endTime = microtime(true);
$executionTime = ($endTime - $startTime) * 1000;
echo "程序执行时间：" . $executionTime . "毫秒";


// int(0)
// int(1)
// int(2)
// int(3)
// int(4)
// 程序执行时间：1.6350746154785毫秒% 
```

多协程的写法性能会有显著提升
注意：如果将 `co::sleep(1);` 替换为 `sleep(1);` 时间又和普通版差不多了
<li>sleep() 可以看做是 CPU密集型任务, 不会引起协程的调度</li>
<li>Co::sleep() 模拟的是 IO密集型任务, 会引发协程的调度</li>

### 例3

> 数据库查询（协程）

```php
$startTime = microtime(true);
run(function () {
    go(function () {
        $mysql = Mysql::getInstance('mysql1');
        $userLogModel = new UserLogModel($mysql);
        $userLogModel->select();
        var_dump('查询');
    });

    go(function () {
        $mysql = Mysql::getInstance('mysql1');
        $userLogModel = new UserLogModel($mysql);
        $userLogModel->select();
        var_dump('查询');
    });

    var_dump('结束');
});
$endTime = microtime(true);
$executionTime = ($endTime - $startTime) * 1000;
echo "程序执行时间：" . $executionTime . "毫秒";
// string(6) "结束"
// string(6) "查询"
// string(6) "查询"
// 程序执行时间：682.88898468018毫秒%   
```

示例3 `go(function () {})` 必须放在协程容器 `run(function () {})` 中，否则无效（查询，查询，结束）
